# ADR template

An ADR (Architecture Decision Record) is a short note explaining why a choice was made, so
future readers don't have to guess. Write one per significant tech choice in a new app.
Never edit an accepted ADR's decision; write a new ADR that supersedes it.

```markdown
# NNNN. <Decision title>

Date: YYYY-MM-DD
Status: Proposed | Accepted | Superseded by NNNN

## Context
The situation and the forces at play.

## Decision
What we chose.

## Alternatives considered
Each option and why it lost.

## Consequences
What gets easier, what gets harder, what we must now maintain.
```
